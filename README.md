# StreamFlix Monorepo

This repository contains the Next.js frontend for a Netflix-like streaming UI.

- nextjs_frontend: Next.js 15 App Router app using Tailwind CSS
- Authentication: Supabase (Google + Email)
- Data: TMDb API
- Persistence: Supabase Postgres (favorites/watchlist)

See nextjs_frontend/README.md for setup and deployment instructions.
